# 사용설명서 화면 사진

여기에 파일을 올리면 `/guide` 설명서에 **그것만으로** 붙습니다. 코드는 고치지
않아도 됩니다.

## 이름 규칙

파일 이름이 곧 자리입니다. 규칙에 안 맞는 이름은 무시되므로, 설명서에 안
보이면 이름부터 확인하세요.

| 파일 | 붙는 자리 |
|---|---|
| `overview.png` | 맨 위 "화면 하나만 기억하시면 됩니다 — OMR 시험" |
| `step-1.png` | 1. 시험 만들기 |
| `step-2.png` | 2. 답안지 뽑기 |
| `step-3.png` | 3. 정답 입력 |
| `step-4.png` | 4. 스캔해서 올리기 |
| `step-5.png` | 5. 검수 |
| `step-6.png` | 6. 주관식 채점 |
| `step-7.png` | 7. 담임 의견 |
| `step-8.png` | 8. 성적표 만들기 |
| `step-9.png` | 9. 발송 |

확장자는 `.png` · `.jpg` · `.webp` 를 받습니다. 아직 안 올린 단계는 글만
나옵니다 — 빈 액자나 깨진 이미지가 뜨지 않습니다.

## 사진 아래 설명

사진마다 한 줄 설명(캡션)이 붙습니다. 그 문구는 `app/guide/page.tsx` 의
`SHOT_CAPTIONS` 에 있습니다. 새 사진을 올릴 때 거기에 한 줄 적어 주세요.
안 적어도 사진은 나오지만, 눈이 어디를 봐야 하는지 짚어 주는 편이 낫습니다.

## 여기 있는 사진은 어떻게 만들었나

손으로 캡처한 것이 아니라, **진짜 화면을 가짜 데이터로 띄워서** 찍었습니다.
화면이 바뀌어 사진이 실제와 달라졌다면 손으로 다시 찍지 마시고
`docs/guide-shots/README.md` 를 보세요 — 명령 한 줄로 아홉 장을 다시 찍습니다.

사진 속 학생 이름·점수·연락처는 모두 지어낸 것입니다.

## 손으로 찍어 올릴 때

- **가로 1400px 이상**으로 찍으세요. 설명서가 넓게 그리므로 작으면 흐려집니다.
- **브라우저 창 전체가 아니라 화면 영역만** 담으면 읽기 쉽습니다. 주소창·다른
  탭 목록은 설명에 도움이 안 됩니다.
- 설명서는 **로그인 없이 열립니다.** 슬랙 안내 DM에서 계정이 아직 없는 신규
  입사자도 바로 열어 보라고 만든 문서입니다. 그러니 사진에 **학생 이름·연락처가
  단 한 줄도 들어가지 않게** 하세요. 직원 이름이 찍히는 것이 걸리면 그 부분만
  가리고 찍으시면 됩니다.
