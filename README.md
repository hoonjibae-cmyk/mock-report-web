# 목동유쌤영어학원 중3 모의고사 웹리포트 v1.5

엑셀 업로드 후 국어·수학·영어 문항을 자동 분석하고, 학생별 웹리포트와 AI 총평 링크를 생성하는 Next.js 웹앱입니다.

## 주요 기능
- 국어·수학·영어 엑셀 업로드 및 자동 채점
- 행동·내용·난이도·학년 수준별 분석
- 전국 상위 추정 및 학원 내 비교
- AI 학습 총평
- 학생별 PIN 보호 웹링크
- 링크 활성화·중지·재발급·삭제·CSV 내보내기
- 관리자 및 일반 사용자 계정 로그인
- 관리자 전용 일반 사용자 등록·권한·비밀번호·활성 상태 관리

## 권한 구조
관리자는 모든 기능을 사용하며 AI 총평 모델을 선택하고 일반 사용자 계정을 관리할 수 있습니다.
일반 사용자는 AI 모델 선택과 계정 관리 기능에는 접근할 수 없습니다. 나머지 기능은 관리자가 사용자별로 허용하거나 제한합니다.

## 기존 v1.4 이하에서 업데이트
1. Supabase SQL Editor에서 `supabase/migration_v1.5_user_accounts.sql` 실행
2. 기존 Vercel 프로젝트에 v1.5 재배포
3. 로그인 후 하단의 `일반 사용자 계정 관리`에서 계정 등록

## 배포 리전
`vercel.json`의 `regions`는 `icn1`(서울)로 고정합니다. Supabase 프로젝트가 서울 리전에 있어, 서버 함수가 같은 곳에서 돌아야 화면마다 여러 번 오가는 DB 왕복이 짧아집니다. 이 값을 지우면 Vercel 기본 리전(미국 동부)으로 돌아가 모든 메뉴 이동이 느려집니다.

## 환경변수
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_USERNAME` — 선택, 기본값 `admin`
- `ADMIN_PASSWORD`
- `AUTH_SECRET`
- `OPENAI_API_KEY` — 선택, 없으면 규칙 기반 총평
- `NEXT_PUBLIC_SITE_URL` — 선택

관리자 로그인은 `ADMIN_USERNAME`과 `ADMIN_PASSWORD`를 사용합니다. 일반 사용자의 아이디와 비밀번호는 관리자 화면에서 등록합니다.

## v1.6 분석 개선

학부모용 AI 총평에서 세부 교과 용어를 쉬운 광역 영역으로 바꾸고, 단기 숙제 대신 여름방학부터 고1 진입 전까지의 학습 로드맵을 제공합니다. 학년 중복 표기와 오답 강조 색상도 개선했습니다.

## v1.8 A4 출력 기능

학부모용 리포트에서 웹·모바일 보기와 A4 출력 미리보기를 전환할 수 있습니다. A4 PDF 저장·인쇄 버튼은 별도 출력 레이아웃을 적용한 뒤 브라우저 인쇄 창을 엽니다. 관리자 목록에서도 웹 보기와 A4 보기 링크를 각각 열 수 있습니다.

## v1.8.1 A4 출력 안정화

A4 페이지의 높이를 고정하고, 하단 푸터를 용지 안쪽에 고정했습니다. 총평이나 분석 내용이 길어지면 인쇄 직전에 해당 페이지의 본문만 자동 축소하여 푸터가 다음 장으로 넘어가거나 빈 페이지가 생기는 현상을 방지합니다.

## v1.8.2 A4 점수 비교 보완

- A4 과목 요약 페이지에 `전국 평균 → 학원 응시자 평균 → 개인 점수` 순서의 3단 막대그래프를 표시합니다.
- 전국·학원·개인을 서로 다른 막대 색상으로 구분합니다.

## 월말평가 → OMR 리포트 연동
시험지 앱의 ‘OMR 리포트로 이어가기’로 현재 작업을 저장하고 보고서 앱의 가져오기 화면을 엽니다. 같은 직원의 슬랙 계정으로 로그인하면 `/admin/omr/new?from=examstudio`에서 담당 응시반을 먼저 선택합니다. 일반 새 시험과 동일한 학생 관리 반 목록·담임 범위를 사용하며 원본의 자유 입력 반명은 응시반에 복사하지 않습니다. 반 선택 후 확정 문항의 최종 인쇄 순서, 1부터 시작하는 정답 번호, 영역·유형·난이도와 배점을 가져옵니다. 원본 배점이 비어 있으면 균등 100점 배점을 명시적으로 선택합니다. 최대 120문항의 월말평가 5지선다를 지원합니다.

30분 유효한 `omr-export` 전용 서명 참조만 URL fragment로 전달합니다(정답·본문은 URL에 넣지 않음). OMR 서버가 고정된 시험지 앱 HTTPS API에서 자료를 가져오고, HR 사번과 업무메일을 현재 계정과 대조합니다. API key나 세션 쿠키를 앱끼리 공유하지 않습니다. 원본 저장 버전이 바뀌면 다시 연동해야 합니다. 기존 AUTH_SECRET·Supabase·HR 설정을 사용하며 추가 운영 환경변수나 DB 마이그레이션은 필요하지 않습니다.

정답·배점·분석 메타데이터·원본 스냅샷은 OMR의 기존 exams 표에 한 번의 INSERT로 저장합니다. 내용과 배점에서 파생한 UUID primary key로 동시 요청·재시도의 중복을 방지합니다. 동일 내용은 기존 시험을 열고 내용이 달라지면 새 채점 시험을 만듭니다. 기존 채점 시험의 정답·리포트는 자동 갱신하지 않습니다. 원본 스냅샷은 omr_config.exam_generator에 보관하고 정답키 화면에서 확인합니다.

## 반배치고사 → 클래스핏 자동 반영

새 반배치고사를 만들 때 `반편성 회차`에서 클래스핏에 등록된 실제 회차를 선택합니다. 회차 ID는 기존 `exams.omr_config.classfit_workspace_id`에 저장하므로 데이터베이스 설치 변경은 없습니다. 기존 시험은 반배정 요청 화면 하단에서 회차를 선택하고 저장할 수 있습니다. 이미 반배정 요청을 보낸 시험의 회차 변경은 제한합니다.

반배정 요청 저장 직후 클래스핏의 서명 검증 API로 성적표 ID를 보내고, 지정 회차에 학생·성적·선호 요일이 반영된 뒤 슬랙으로 알립니다. 두 프로그램이 기존에 공유하는 Supabase 서버 키를 용도별 HMAC 서명에 사용하며 키나 학생 자료를 URL에 싣지 않습니다. 전송 실패 시 요청은 보존하고 기존 예약 실행이 재시도합니다. 같은 요청은 중복 학생을 만들지 않습니다.

슬랙 알림은 새 카드 디자인을 사용하며 링크가 해당 회차·학년을 엽니다. 클래스핏을 열어 둔 경우에는 편집 중이 아닐 때 목록이 자동 갱신됩니다.

### v1.54.1 · Studio 연동 응시반 선택

공개 `/exam-import` 진입점에서 서명 참조를 세션에 보관한 뒤 OMR 새 시험 화면으로 이동하므로 로그인 전후에도 연동을 유지합니다. 반 선택→문항·정답 확인→생성 순서이며 서버에서 현재 반 목록을 다시 검증합니다. 반 미선택·목록 오류·담당 범위 밖 반은 생성할 수 없습니다. 같은 계정·응시반 집합·시험 내용만 재사용하고, 다른 반은 별도 시험으로 만듭니다. 이전 연동·채점 시험을 덮어쓰지 않습니다.

### v1.54.2 · 기존 연동 시험의 응시반 수정

기존 이그잼 스튜디오 연동 월말평가의 정답 입력·성적표 생성 화면에서 **응시반 변경**을 누르면 실제 담당 반을 다시 선택할 수 있습니다. 만든 사람 또는 관리자만 수정합니다. 현재 반 목록을 서버에서 검증하고 이전 반 목록을 기준으로 조건부 갱신하여 동시 수정 충돌을 차단합니다. `exams.class_names`만 같은 시험 행에서 변경하며 시험 ID·스캔·정답키·배점·채점·성적표 링크·코멘트·발송 기록은 유지합니다. 명단·미응시 조회는 새 반 기준으로 진행하며 기존 성적표 표기·평균의 갱신은 별도 실행합니다. 추가 마이그레이션은 없습니다.
