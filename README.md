# 목동유쌤영어학원 중3 모의고사 웹리포트 v1.5

엑셀 업로드 후 국어·수학·영어 문항을 자동 분석하고, 학생별 웹리포트와 AI 총평 링크를 생성하는 Next.js 웹앱입니다.

## 주요 기능
- 국어·수학·영어 엑셀 업로드 및 자동 채점
- 행동·내용·난이도·학년 수준별 분석
- 전국 상위 추정 및 학원 내 비교
- AI 학습 총평
- 학생별 PIN 보호 웹링크
- 링크 활성화·중지·재발급·삭제·CSV 내보내기
- 관리자 및 일반 사용자 계정 로그인
- 관리자 전용 일반 사용자 등록·권한·비밀번호·활성 상태 관리

## 권한 구조
관리자는 모든 기능을 사용하며 AI 총평 모델을 선택하고 일반 사용자 계정을 관리할 수 있습니다.
일반 사용자는 AI 모델 선택과 계정 관리 기능에는 접근할 수 없습니다. 나머지 기능은 관리자가 사용자별로 허용하거나 제한합니다.

## 기존 v1.4 이하에서 업데이트
1. Supabase SQL Editor에서 `supabase/migration_v1.5_user_accounts.sql` 실행
2. 기존 Vercel 프로젝트에 v1.5 재배포
3. 로그인 후 하단의 `일반 사용자 계정 관리`에서 계정 등록

## 환경변수
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `ADMIN_USERNAME` — 선택, 기본값 `admin`
- `ADMIN_PASSWORD`
- `AUTH_SECRET`
- `OPENAI_API_KEY` — 선택, 없으면 규칙 기반 총평
- `NEXT_PUBLIC_SITE_URL` — 선택

관리자 로그인은 `ADMIN_USERNAME`과 `ADMIN_PASSWORD`를 사용합니다. 일반 사용자의 아이디와 비밀번호는 관리자 화면에서 등록합니다.

## v1.6 분석 개선

학부모용 AI 총평에서 세부 교과 용어를 쉬운 광역 영역으로 바꾸고, 단기 숙제 대신 여름방학부터 고1 진입 전까지의 학습 로드맵을 제공합니다. 학년 중복 표기와 오답 강조 색상도 개선했습니다.

## v1.8 A4 출력 기능

학부모용 리포트에서 웹·모바일 보기와 A4 출력 미리보기를 전환할 수 있습니다. A4 PDF 저장·인쇄 버튼은 별도 출력 레이아웃을 적용한 뒤 브라우저 인쇄 창을 엽니다. 관리자 목록에서도 웹 보기와 A4 보기 링크를 각각 열 수 있습니다.

## v1.8.1 A4 출력 안정화

A4 페이지의 높이를 고정하고, 하단 푸터를 용지 안쪽에 고정했습니다. 총평이나 분석 내용이 길어지면 인쇄 직전에 해당 페이지의 본문만 자동 축소하여 푸터가 다음 장으로 넘어가거나 빈 페이지가 생기는 현상을 방지합니다.

## v1.8.2 A4 점수 비교 보완

- A4 과목 요약 페이지에 `전국 평균 → 학원 응시자 평균 → 개인 점수` 순서의 3단 막대그래프를 표시합니다.
- 전국·학원·개인을 서로 다른 막대 색상으로 구분합니다.
